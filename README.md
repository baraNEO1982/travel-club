# Клуб путешественников

Семейный сайт: регистрация только по одноразовому приглашению, вход по логину и паролю, рассказы, фотографии и комментарии.

Предварительная публикация: https://travel-club.baraneo-family-club.workers.dev/

Статус: локальные проверки пройдены; на опубликованном сайте проверены регистрация, вход, рассказы, комментарии, небольшие фото и запрет анонимного доступа. Крупные загрузки и JS интерфейса обрываются в текущей сети (около19 КБ). Требуется решить вопрос сетевой доступности перед семейным использованием. Старый GitHub Pages пока сохранён.

## Устройство
- React/Vite: source/app/club.tsx
- Cloudflare Worker: source/worker/club.ts
- D1: участники, хэши паролей (scrypt), хэши сессий и приглашений, рассказы и комментарии.
- KV: приватные фотографии. Каждое чтение проверяет сессию через Worker.
- Приглашения одноразовые, действуют 7 дней. Гашение защищено правилами базы от одновременной регистрации.
- Cookie сессии: Secure, HttpOnly, SameSite=Strict. Запись проверяет Origin; вход ограничен по частоте.
- Фото уменьшаются до 1600 пикселей и 1 МБ, до 12 новых за раз, до 100 на рассказ. При повторной загрузке используются те же идентификаторы.
- Платные планы и R2 не используются. Приложение ограничивает фото общим бюджетом900 МБ; остаются также дневные лимиты бесплатного Cloudflare.

## Разработка
В папке source: npm ci, затем npm run build:web. Проверка типов: npx tsc --noEmit. Серверные проверки: node tests/club-api.mjs.
Для собственного аккаунта замените идентификаторы ресурсов в wrangler.club.jsonc. Примените миграции командой npx wrangler d1 migrations apply travel-club --remote --config wrangler.club.jsonc. Публикация: npx wrangler deploy --config wrangler.club.jsonc.
Первое приглашение создаётся администратором в базе: случайный секрет передаётся владельцу отдельно, в таблицу invitations записывается только SHA-256. Секреты, пароли и семейные записи не должны попадать в репозиторий.

Старые файлы Supabase сохранены в истории репозитория; опубликованная версия использует Cloudflare. Код восстановления по почте добавлен; настоящая доставка требует подключения почтового сервиса (см. source/EMAIL-SETUP.md).

## Дополнение путешествий
Автор может редактировать название, место и текст, добавлять новые фото к тому же рассказу. Изменения проверяют версию, чтобы не затереть правки из другой вкладки. Описания фото меняет автор, отдельные комментарии к каждому фото могут писать все участники. Миграция0002 сохраняет существующие данные.

## Восстановление пароля
«Моя почта» привязывает адрес после текущего пароля и подтверждения письмом. «Забыли пароль?» отправляет одноразовую ссылку на подтверждённый адрес. Срок30 минут; смена пароля закрывает старые сессии. До настройки BREVO_API_KEY и EMAIL_FROM отправка отключена и сайт сообщает об этом. Проверки с имитацией почты: node tests/recovery.mjs; реальная доставка пока не проверена.
