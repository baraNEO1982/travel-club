# Клуб путешественников

Закрытые семейные рассказы о путешествиях, фотографии и комментарии.

Интерфейс: https://baraneo1982.github.io/travel-club/

## Приватность
Содержимое поездок и фотографии находятся в Supabase, не в этом репозитории. Доступ определяется проверками членства и Row Level Security. Файловое хранилище закрытое. Регистрация требует одноразового приглашения, привязанного к почте. Приглашения действуют 7 дней; их могут создавать участники.

Публичный ключ Supabase в исходниках предназначен для браузера; он не предоставляет административный доступ.

## Сборка
Исходники в source. Node.js 22.13+. Из source: npm ci, затем npm run build:web. Содержимое source/dist-web публикуется в корень репозитория.

## Незавершённая настройка
Нужно настроить SMTP в Supabase и URL возврата https://baraneo1982.github.io/travel-club/ перед использованием регистрации и восстановления пароля. Настройки не содержатся в этом репозитории.
