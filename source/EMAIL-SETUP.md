# Подключение почты для восстановления

Код готов; отправка отключена, пока не заданы оба секрета Cloudflare: BREVO_API_KEY и EMAIL_FROM. Без них формы честно сообщают, что отправка не подключена.

1. Создать аккаунт Brevo на бесплатном плане (без карты); подтвердить свой адрес и пройти проверку аккаунта провайдером, если её предложат.
2. В Senders & Domains создать и подтвердить адрес отправителя. Для адресов бесплатной почты Brevo может подставлять свой домен; фактическую доставку требуется проверить. Не подключать платный план.
3. В SMTP & API → API Keys создать ключ. Нужен API-ключ, не SMTP-пароль.
4. На Mac запустить `python3 scripts/configure-email.py` из папки travel-club. Скрипт спросит адрес и скрыто запросит ключ; ключ не сохраняется в файлах и передаётся прямо в Cloudflare Secrets. Альтернатива — добавить оба секрета в настройках Worker travel-club в Cloudflare. Ключ не присылать в чат.
5. После настройки открыть сайт → Моя почта → ввести email и текущий пароль → подтвердить ссылку из письма. Уже существующий email не назначается участнику автоматически.
6. Проверить в отдельном браузере «Забыли пароль?», доставку ссылки, новый вход и недействительность старой сессии. Локальные автоматические проверки используют имитацию доставки; они не подтверждают настоящую доставку.

Ссылки действуют 30 минут, одноразовые. В базе только хэши секретов. Привязка требует текущий пароль и подтверждение почты; восстановление работает только для подтверждённого адреса. Смена пароля закрывает старые сессии и гасит остальные ссылки. Ответ на запрос сброса одинаков для существующего и неизвестного адреса. Ограничения: до150 писем/сутки для всего клуба, плюс лимиты на пользователя и IP. SMTP Mail.ru и ранее переданные пароли не используются.
