# Клуб путешественников — iPhone

SwiftUI, iOS 17+. Откройте TravelClub.xcodeproj в Xcode 26.3 или новее.

20 октября 2026: основной сервер — https://marshrutclub.ru. Старые ссылки
приглашений также поддерживаются. Старые сборки используют совместимый
шлюз Cloudflare; новая сборка обращается прямо к Timeweb.

## Возможности
- Вход и выход через тот же сервер, что и сайт.
- Регистрация только по приглашению: вставьте ссылку из сообщения в форму приложения.
- Путешествия с фотографиями, автором и датой; чтение рассказа.
- Комментарии к путешествию и каждому фото, обновление обсуждений.
- Изменение описания фото автором путешествия.
- Создание и дополнение рассказов, выбор фото из медиатеки.
- До 12 новых фото за раз, до 100 на путешествие; до 10 МБ исходник. Сжатие до 1600 px и 1 МБ JPEG без исходных EXIF-данных.
- Повторная отправка частично сохранённого рассказа/фото без дублирования, стабильные ID; проверка версии при редактировании.
- Создание одноразовых приглашений и системное меню «Поделиться».
- Привязка email, запрос сброса пароля, ввод ссылки из письма для подтверждения/смены пароля.

Письма пока не настроены на сервере (Brevo). Формы показывают реальное состояние сервиса и не обещают отправку. Ссылки открываются на сайте; для выполнения внутри приложения вставьте их в соответствующую форму. Universal Links пока не настроены.

## Приватность
Фото и JSON используют одну приватную URLSession и авторизованную cookie. Пароль не сохраняется, сессия живёт только до закрытия процесса. Сервер контролирует доступ, приглашения и права автора. Изображения не кэшируются приложением на диск. Для доступа к выбранным фото используется системный PhotosPicker.

## Проверка 16 октября 2026
- Полная Debug-сборка Xcode 26.3 для iOS Simulator прошла.
- Проверены на экране формы входа, регистрации и восстановления.
- Tests/ClubModelChecks.swift: тестовые ответы API — фото/рассказы, комментарии, подписи, приглашения, конфликт версии, недоступность почты, заголовки отправки, повторная загрузка и выход. Реальные записи не изменяются.
- Tests/PhotoChecks.swift: локальная проверка преобразования изображения, размеров, лимита файла и отклонения повреждённых данных.
- Полная проверка всех действий с реальным сервером после обновления ещё не завершена: включённый Happ Plus сопровождается ошибкой DNS в симуляторе. На Mac тот же URLSession подключается; два симулятора не находят даже apple.com. Пользователь сообщил, что после временного отключения VPN рассказы появились. VPN затем восстановлен на прежнем сервере, настройки не редактировались.
- На физическом iPhone пока не проверено. Для локальной установки выберите свою Personal Team в Signing & Capabilities. Платное членство для теста на своём устройстве не требуется.

## Локальные проверки
Укажите DEVELOPER_DIR, если Xcode не выбран системным:

```sh
export DEVELOPER_DIR=/Users/user/Downloads/Xcode.app/Contents/Developer
xcrun swiftc -parse-as-library TravelClub/ClubModel.swift Tests/ClubModelChecks.swift -o /tmp/club-model-checks
/tmp/club-model-checks
xcodebuild -project TravelClub.xcodeproj -scheme TravelClub -destination 'generic/platform=iOS Simulator' -derivedDataPath /tmp/travel-club-ios-build CODE_SIGNING_ALLOWED=NO build
```

Тест PhotoChecks собирается для arm64 iOS Simulator вместе с ClubModel.swift и JourneyEditor.swift; запускается через simctl spawn на загруженном симуляторе.

## Восстановление соединения
16 октября: в старом процессе приложения зафиксированы обрывы HTTP/3 (-1005), в свежем клиенте публичные запросы и тестовый POST отвечают быстро. Перед входом без активного участника выполняется URLSession.reset; при сетевой ошибке — flush, без автоматического повторения POST. Локальные проверки прошли; исправленный клиент на симуляторе дважды получил ожидаемый 401 для вымышленной учётной записи. Вход пользователя после обновления ещё требует проверки. VPN при этой проверке не менялся и был отключён.
